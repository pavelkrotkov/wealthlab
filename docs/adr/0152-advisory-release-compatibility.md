# Advisory fees through reproducible local reports

Status: unpublished integration above the common advisory consumer (ADR0207), combining the original native local-release and drilling-offer ancestry. No public parent is rewritten and no new QOZ exit or offer implementation is imported by this layer.

## One calculation and one serialization boundary

CLI and UI policy reports execute the same native optimizer with the exact common sourced fee plan. Each candidate observes its actual marks, pays from the existing cash pool and retains actual unpaid fees. Fees do not change original capital, share basis or tax eligibility. The complete drilling envelope still covers the normalized search, including fee assumptions. Adding fees cannot automatically reconfirm a supplied envelope.

A compatibility check found that downloads and CLI output correctly encoded nested typed NJ business-loss records, while Streamlit's default JSON display converted those nested records and Decimal amounts to representation strings. The visible optimizer, held-out, robustness and household reproduction views now use the existing finite structured report encoder. Canonical engine/session objects remain typed; the UI receives already serialized JSON. Unknown objects and nonfinite amounts retain the encoder's explicit rejection.

## Actual economic and replay checks

An original fee-enabled well begins with $200,000, funds $100,000 native costs and exits for $40,000. Monthly sourced outer fees consume $1,105.97 separately from embedded manager costs, leaving $138,894.03 cash and no fee debt. The actual return retains a typed `BusinessLoss(year=2026, amount=60000)`; CLI and visible UI report it as structured year/amount fields. An independent calendar-day recurrence applies the supplied 1% first-$100,000 and 0.5% excess marginal rates to current cash plus the $20,000 property mark, then replaces property with the actual $40,000 final sale. It independently reproduces both paid fees and closing cash. Both complete report payloads agree, including actual installed dependencies and source metadata.

Report imports validate the unchanged input fingerprint, discard archived outcomes and execute again. Forged selection, inflated cash, erased fees and deleted NJ loss carry cannot alter the reproduced result. Changing the fee contract while retaining an old fingerprint fails. An original $350,000 invoice pays the available $253,999, retains $96,001 debt and produces no completed-exit selection. These checks supplement ADR0207's same-capital option/new-life comparisons.

All examples are original synthetic data. Commands capture explicit stdout in memory and leave only their selected synthetic input in isolated test-runtime directories. Native fee-enabled selected output inside the actual public checkout is refused. Existing release checks retain atomic/exclusive private-output semantics, linked-worktree and symlink protection, offline calculation, bounded imports and sanitized errors. No external private records or output directory are used by this integration verification.
