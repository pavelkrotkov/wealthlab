# Reproduce bounded policy searches through the local UI and CLI

The existing optimizer already owns training enumeration, frozen selection, independent validation and actual native market/household books. Release integration exposes it through `python -m wealthlab optimize` rather than introducing another calculation engine. The existing selected-directory atomic no-overwrite output writer, sanitized CLI errors, loopback launcher and household report serializer remain shared.

Both the UI and CLI attach the same normalized input fingerprint, source revision/dirty state and installed dependency metadata. The complete audit preserves seeds, realized paths, evaluated policies, conditional/full-tax limitations and actual native monthly tax/cash rows. JSON export supports only finite typed amounts/dates; unknown structured objects cannot silently become display strings. Household projection fingerprints retain their original representation; the shared helper merely also accepts the validated search model.

Raw inputs or a bounded search audit can be imported. Audit import validates its input fingerprint, discards archived outcomes and performs a fresh search under current code. A checksum detects edits but authenticates neither legal facts nor source documents. Inputs are UTF-8/BOM-compatible and bounded at2MB; a large audit must use its separate input export for replay. Private selected-file output remains outside every public checkout, exclusive and atomic. No scenario is sent over the network by the calculation.

Native CLI and actual Streamlit UI checks require identical full search results, independently verified cash251999 for the early flat case, frozen selection/seed separation, source identity and actual installed tax-engine version. Further checks reject edited fingerprints, discard forged archived outcomes, preserve exact selected-output bytes on overwrite attempts, sanitize invalid private inputs and deny implicit optimizer network connections. This feature does not certify the remaining product/jurisdiction integrations or close the release ticket.
