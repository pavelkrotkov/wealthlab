# Puerto Rico annual implementation and remaining integration

Issue #15 is delivered through an annual ordinary layer and a dependent incentive/gain layer. This document records bounded support; it does not close the issue before both layers and their exact-head gates pass.

| Requirement | Ordinary annual layer | Incentive layer / remaining integration |
| --- | --- | --- |
| Editable residence, income sources and comparison | Annual tax → Puerto Rico annual; every original synthetic receipt and dated claim editable, mainland US/NJ baseline retained | Editable dated decree and gain inputs; durable original synthetic examples |
| Separate federal/PR computations and credits | Federal section 933 allocation, raw payroll; PR ordinary regular/ABT, separate credit audit | Supported 15%/all-ordinary comparison; separate conditional 0%/4%/5% buckets |
| Unconfirmed eligibility | Withheld candidate with reasons; assumed facts prominently conditional; no inferred grant | Ordinary alternative retained with denied/unset decree; assumptions stay conditional |
| Pre-move appreciation | Gains are explicitly guarded in ordinary-only layer | Independent federal/PR cost/move-FMV/sale allocation, federal election/lookback and local ten-year boundary |
| Independent checks | Brackets, statutory cap, ABT bands, source/date/reconciliation, credits, real UI correction | Application/sunset/ten-year boundaries, published FMV example, no-election paid-tax reduction, real UI |
| Actual household relocation | Explicitly not implied by annual output | Cross-border integration #17: monthly funding, state departure, optimizer |
